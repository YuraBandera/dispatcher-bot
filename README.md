# ШІ-Диспетчер екстрених служб — Discord-бот

Текстовий Roleplay-диспетчер 102/103 на `discord.py` 2.x + Gemini (`google-genai`).
Слухає канал викликів, веде діалог у гілці, збирає 3 пункти (суть, локація, постраждалі)
і після тега `[ВИКЛИК_ЗАВЕРШЕНО]` надсилає рапорт у канал фракції з пінгом ролі.

## Локальний запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # заповни реальними значеннями
python dispatcher_bot.py
```

## Обовʼязкові налаштування Discord

1. Developer Portal → Bot → увімкни **Message Content Intent** (привілейований).
2. Права бота в **каналі викликів**: Створювати публічні гілки, Писати в гілках, Керувати гілками.
3. Права бота в **каналі фракції**: Згадувати всі ролі (або зроби роль «mentionable»).

## Деплой на Railway (24/7)

1. Заливаєш проєкт у GitHub-репозиторій (`.env` не комітиться — він у `.gitignore`).
2. Railway → New Project → Deploy from GitHub repo → обираєш репозиторій.
3. Вкладка **Variables** → додаєш усі змінні з `.env.example` реальними значеннями.
4. Railway сам збере й запустить процес (`Procfile` каже, що це `worker`, а не веб-сервіс).

Історія діалогів зберігається в памʼяті процесу: після редеплою/рестарту активні виклики обнуляються.
